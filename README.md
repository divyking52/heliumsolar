# Helium Solar

Standalone scroll experience + Next.js app for Helium Solar.

## Standalone HTML

Open locally:

- `helium-solar.html` (keep `images/` and `videos/` beside it)
- or `public/helium-solar.html` via the Next server

Live path after deploy: `/helium-solar.html` (root `/` redirects there)

## Develop

```bash
npm install
npm run dev
```

## Deploy

Connected to GitHub → Vercel production deploys from `main` / `master`.
